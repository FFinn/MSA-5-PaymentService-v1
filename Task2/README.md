# Таблица переходов состояний платежа

В таблице перечислены все переходы состояний экземпляра Saga. Оркестратор рассчитывает срок ручной проверки и контрольный срок. В тестовой конфигурации время ожидания можно сократить параметром окружения; в рабочем контуре оно остаётся равным 20 минутам.

| Исходное состояние | Переходное состояние | Событие |
|---|---|---|
| `NEW` | `DEBITTING` | Получена команда на создание платежа; данные и лимиты прошли предварительную проверку. |
| `DEBITTING` | `DEBITED` | Получено подтверждение списания со счёта плательщика. |
| `DEBITTING` | `REJECTED` | Банк отказал в списании; деньги не списаны. |
| `DEBITTING` | `DEBIT_RECONCILIATION` | Истёк срок ответа банка, а результат списания неизвестен. |
| `DEBIT_RECONCILIATION` | `DEBITED` | Банк подтвердил, что списание выполнено. |
| `DEBIT_RECONCILIATION` | `REJECTED` | Банк подтвердил, что списание не выполнено. |
| `DEBITED` | `FRAUD_CHECKING` | Оркестратор направил запрос на антифрод-проверку. |
| `FRAUD_CHECKING` | `APPROVED` | Антифрод-сервис вернул разрешение. |
| `FRAUD_CHECKING` | `MANUAL_REVIEW_WAIT` | Антифрод-сервис запросил ручную проверку. |
| `FRAUD_CHECKING` | `APPROVED` | Истёк контрольный срок ожидания ответа сервиса проверок; применяется правило «разрешить». |
| `FRAUD_CHECKING` | `RETURNING` | Антифрод-сервис вернул запрет. |
| `MANUAL_REVIEW_WAIT` | `APPROVED` | Оператор завершил ручную проверку с решением «разрешить». |
| `MANUAL_REVIEW_WAIT` | `RETURNING` | Оператор завершил ручную проверку с решением «запретить». |
| `MANUAL_REVIEW_WAIT` | `APPROVED` | Через 20 минут не получено окончательное решение; сработал контрольный срок. |
| `APPROVED` | `TRANSFERRING` | Оркестратор сформировал идемпотентную команду на перевод контрагенту. |
| `TRANSFERRING` | `COMPLETED` | Платёжный провайдер подтвердил перевод; пройдена точка невозврата. |
| `TRANSFERRING` | `TRANSFER_RECONCILIATION` | Ответ на перевод не получен или технически неоднозначен. |
| `TRANSFERRING` | `RETURNING` | Провайдер однозначно подтвердил невозможность перевода. |
| `TRANSFER_RECONCILIATION` | `COMPLETED` | Уточняющий запрос подтвердил, что перевод уже проведён. |
| `TRANSFER_RECONCILIATION` | `RETURNING` | Уточняющий запрос подтвердил, что перевод не проведён. |
| `RETURNING` | `REFUND_RECONCILIATION` | Срок ответа на возврат истёк; результат возврата требует уточнения. |
| `RETURNING` | `REFUNDED` | Банк подтвердил автоматический возврат плательщику. |
| `REFUND_RECONCILIATION` | `REFUNDED` | Уточняющий запрос подтвердил возврат; при необходимости запрос повторяется с прежним ключом идемпотентности. |
| `REFUNDED` | `CLOSED` | Финансовый результат зафиксирован, уведомления записаны в таблицу исходящих сообщений. |
| `COMPLETED` | `CLOSED` | Финансовый результат зафиксирован, уведомления записаны в таблицу исходящих сообщений. |
| `REJECTED` | `CLOSED` | Платёж завершён без списания денег. |

В состояниях `DEBIT_RECONCILIATION`, `TRANSFER_RECONCILIATION` и `REFUND_RECONCILIATION` результат операции нельзя предполагать. Это помогает исключить двойное списание, двойной перевод и возврат до подтверждения фактического состояния у провайдера.
