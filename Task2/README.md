# Таблица переходов состояний платежа

Таблица описывает состояние экземпляра Saga. Срок ручной проверки и контрольный срок рассчитывает оркестратор. Для проверки таблицы в автоматических тестах допускается сократить 20 минут параметром окружения, но рабочее значение остаётся равным 20 минутам. Состояние меняется атомарно: решение оператора, ответ антифрода и таймер не могут одновременно назначить разные финансовые маршруты.

| Исходное состояние | Переходное состояние | Событие |
|---|---|---|
| `NEW` | `DEBITING` | Получена команда на создание платежа; данные и лимиты прошли предварительную проверку. |
| `NEW` | `REJECTED` | Предварительная проверка данных или лимитов не пройдена; списание не выполнялось, созданный платёж отменён компенсацией `CANCEL_PAYMENT`. |
| `DEBITING` | `DEBITED` | Получено подтверждение списания со счёта плательщика. |
| `DEBITING` | `REJECTED` | Банк отказал в списании; деньги не списаны. |
| `DEBITING` | `DEBIT_RECONCILIATION` | Истёк срок ответа банка, а результат списания неизвестен. |
| `DEBIT_RECONCILIATION` | `DEBITED` | Банк подтвердил, что списание выполнено. |
| `DEBIT_RECONCILIATION` | `REJECTED` | Банк подтвердил, что списание не выполнено. |
| `DEBIT_RECONCILIATION` | `DEBIT_RECONCILIATION` | Банк пока не установил статус; оркестратор назначил следующую попытку сверки. |
| `DEBIT_RECONCILIATION` | `FINANCIAL_RECONCILIATION_REQUIRED` | Истёк срок сверки, а банк не подтвердил ни списание, ни его отсутствие. |
| `FINANCIAL_RECONCILIATION_REQUIRED` | `DEBITED` | Финансовая сверка подтвердила, что списание было выполнено; процесс продолжает проверку платежа. |
| `FINANCIAL_RECONCILIATION_REQUIRED` | `REJECTED` | Финансовая сверка подтвердила, что списание не было выполнено; платёж завершается без возврата. |
| `DEBITED` | `FRAUD_CHECKING` | Оркестратор направил запрос на антифрод-проверку. |
| `FRAUD_CHECKING` | `APPROVED` | Антифрод-сервис вернул разрешение. |
| `FRAUD_CHECKING` | `MANUAL_REVIEW_WAIT` | Антифрод-сервис запросил ручную проверку. |
| `FRAUD_CHECKING` | `APPROVED` | Истёк контрольный срок ожидания ответа сервиса проверок; применяется правило «разрешить». |
| `FRAUD_CHECKING` | `RETURNING` | Антифрод-сервис вернул запрет. |
| `MANUAL_REVIEW_WAIT` | `APPROVED` | Оператор завершил ручную проверку с решением «разрешить». |
| `MANUAL_REVIEW_WAIT` | `RETURNING` | Оператор завершил ручную проверку с решением «запретить». |
| `MANUAL_REVIEW_WAIT` | `APPROVED` | Через 20 минут не получено окончательное решение; сработал контрольный срок. |
| `APPROVED` | `TRANSFERRING` | Оркестратор сформировал идемпотентную команду на перевод контрагенту. |
| `TRANSFERRING` | `COMPLETED` | Платёжный провайдер подтвердил перевод; пройдена точка невозврата. |
| `TRANSFERRING` | `TRANSFER_RECONCILIATION` | Ответ на перевод не получен или технически неоднозначен. |
| `TRANSFERRING` | `RETURNING` | Провайдер однозначно подтвердил невозможность перевода. |
| `TRANSFER_RECONCILIATION` | `COMPLETED` | Уточняющий запрос подтвердил, что перевод уже проведён. |
| `TRANSFER_RECONCILIATION` | `RETURNING` | Уточняющий запрос подтвердил, что перевод не проведён. |
| `TRANSFER_RECONCILIATION` | `TRANSFER_RECONCILIATION` | Провайдер пока не установил статус; оркестратор назначил следующую попытку сверки. |
| `TRANSFER_RECONCILIATION` | `FINANCIAL_RECONCILIATION_REQUIRED` | Истёк срок сверки, а провайдер не подтвердил ни перевод, ни его отсутствие. |
| `FINANCIAL_RECONCILIATION_REQUIRED` | `COMPLETED` | Финансовая сверка подтвердила, что перевод контрагенту был выполнен. |
| `FINANCIAL_RECONCILIATION_REQUIRED` | `RETURNING` | Финансовая сверка подтвердила, что перевод контрагенту не был выполнен, при этом списание с плательщика уже подтверждено. |
| `RETURNING` | `REFUND_RECONCILIATION` | Срок ответа на возврат истёк; результат возврата требует уточнения. |
| `RETURNING` | `REFUNDED` | Банк подтвердил автоматический возврат плательщику. |
| `REFUND_RECONCILIATION` | `REFUNDED` | Уточняющий запрос подтвердил возврат. |
| `REFUND_RECONCILIATION` | `RETURNING` | Банк подтвердил, что возврат не выполнен, но ошибка повторяема; команда повторяется с прежним ключом идемпотентности. |
| `REFUND_RECONCILIATION` | `REFUND_RECONCILIATION_REQUIRED` | Истёк срок сверки, а банк не подтвердил результат возврата. Требуется финансовая сверка статуса, но не ручное выполнение возврата поддержкой. |
| `RETURNING` | `REFUND_RECONCILIATION_REQUIRED` | Банк подтвердил, что возврат не выполнен, но причина не позволяет безопасно повторять его автоматически без финансовой сверки. |
| `REFUND_RECONCILIATION_REQUIRED` | `REFUNDED` | Финансовая сверка подтвердила, что возврат уже выполнен. |
| `REFUND_RECONCILIATION_REQUIRED` | `RETURNING` | Финансовая сверка подтвердила, что возврат не выполнен и его можно повторить автоматически с прежним ключом идемпотентности. |
| `REFUNDED` | `CLOSED` | Финансовый результат зафиксирован, уведомления помещены в таблицу исходящих сообщений. |
| `COMPLETED` | `CLOSED` | Финансовый результат зафиксирован, уведомления помещены в таблицу исходящих сообщений. |
| `REJECTED` | `CLOSED` | Платёж завершён без списания денег. |

Состояния `DEBIT_RECONCILIATION`, `TRANSFER_RECONCILIATION` и `REFUND_RECONCILIATION` не допускают угадывания результата. Это исключает двойное списание, двойной перевод или возврат до подтверждения фактического состояния у провайдера. `FINANCIAL_RECONCILIATION_REQUIRED` хранит тип операции, по которой открыта сверка: списание или перевод. `FINANCIAL_RECONCILIATION_REQUIRED` и `REFUND_RECONCILIATION_REQUIRED` не являются успешным окончанием процесса: до решения финансовой сверки платёж не переводится в `CLOSED`, а Customer Support не выполняет финансовые операции вручную.
