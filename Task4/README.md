# BPMN-схема процесса обработки платежа

Файл [`payment-process.jpg`](payment-process.jpg) показывает основу исполнимой BPMN-модели для Camunda.

Схема отражает:

1. списание и антифрод-проверку;
2. развилки «разрешить», «запретить» и «ручная проверка»;
3. ожидание ручного решения до 20 минут и разрешение по контрольному сроку (cut-off-time);
4. фактический перевод контрагенту как точку невозврата;
5. автоматический возврат при запрете или подтверждённой ошибке перевода;
6. уточнение статуса при неоднозначном результате, чтобы не вернуть деньги при уже проведённом переводе.

В реализации задачи вызов сервисов следует оформить внешними задачами либо сообщениями. В BPMN остаются последовательность, ожидания, сроки и ветвления; финансовые правила и вызовы провайдеров остаются в соответствующих сервисах.
